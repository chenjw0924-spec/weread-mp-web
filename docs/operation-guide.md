# WeRead MP Web 操作指引

本文说明从扫码登录到批量导出公众号文章的完整流程。页面不保存访问密码，打开后直接进入微信读书连接流程。

## 1. 连接微信读书

1. 打开网站首页，等待二维码出现。
2. 使用手机 **微信 App** 的“扫一扫”扫描二维码，在手机上确认登录。不要使用微信读书 App 内的扫码入口。
3. 如果手机确认后要求双重验证，网页会显示“手机显示的 4 位验证码”输入框。把手机上显示的 4 位数字填入网页并提交，等待状态变为“连接成功”。
4. 连接成功后，页面会加载你在微信读书中关注的公众号。

二维码通常只在当前会话内有效。出现“二维码已过期”或“微信读书登录未完成”时，点击“重新生成二维码”，再完整扫码一次。不要关闭扫码窗口或刷新页面后再等待旧二维码；刷新会创建新的匿名会话。

如果网页一直显示“已扫码，请在手机上确认登录”，请先确认手机上的登录确认已经完成，再等待几秒。如果手机已经提示 4 位验证码但网页没有输入框，先点击“重新生成二维码”重试；二维码任务和验证码必须属于同一个浏览器会话。

## 2. 选择公众号

连接完成后，左侧显示已关注公众号：

- 用搜索框按名称过滤。
- 点击星标收藏公众号；收藏只保存在当前浏览器，不会上传到服务端。
- 使用“全部 / 已收藏”切换列表。
- 新关注的公众号需要点击“刷新”或重新连接后才会出现在列表中。

点击公众号名称后，右侧会读取文章列表。首次读取默认查询最近 1 年，页面显示上游实际返回的最早和最新日期。

## 3. 按日期读取文章

如果默认范围不合适，在文章列表上方填写开始日期或结束日期，点击“按日期读取”。日期查询会继续读取上游分页，直到命中日期边界、上游没有更多内容或达到单次安全上限。

页面只展示微信读书实际返回的文章。未公开接口可能无法提供完整历史内容；如果结果少于预期，请扩大日期范围、重新读取，或确认该公众号在微信读书中仍然处于关注状态。

## 4. 批量导出 Markdown ZIP

1. 在文章列表中勾选需要保存的文章，也可以使用全选。
2. 点击底部“下载文章”。
3. 可选打开“同时下载图片”。关闭时 Markdown 保留原图链接；打开时服务会尝试把图片放入 ZIP。
4. 点击“开始下载”，在进度窗口查看逐篇状态。
5. 任务完成后点击“下载 ZIP”。浏览器下载记录中会出现 `weread-articles.zip`。

如果部分文章或图片失败，窗口会显示失败数量和原因。点击“重试失败项”只重新处理失败文章；此前成功的文章仍可单独下载。图片下载失败不会静默丢失，Markdown 会保留原始图片地址。

## 5. 连接过期和断开

微信读书 Cookie 只保存在当前服务进程的内存中。以下情况会使连接失效：

- 主动点击“断开连接”。
- 会话超过有效期。
- 本地服务重启、Docker 容器重启或 Vercel Function 实例被回收。
- 微信读书上游要求重新登录。

出现“连接已过期”时，点击“重新连接”并重新扫码。已勾选的文章会在当前页面尽量保留，但过期后需要重新读取文章列表才能继续导出。

## 6. 部署和安全

本地开发建议使用单 worker：

```bash
export COOKIE_SECURE=false
uvicorn app.main:app --host 127.0.0.1 --port 8765 --workers 1
```

Docker Compose 默认只监听 `127.0.0.1:8765`。通过反向代理给其他设备访问时使用 HTTPS，并保持 `COOKIE_SECURE=true`；同时在代理、VPN 或防火墙层增加访问控制。网站本身不设置访问密码，不能把 Uvicorn 端口直接暴露到公网。

Vercel 部署适合个人低频使用和预览。Vercel Function 不保证实例固定，扫码任务、会话和后台导出任务可能因实例回收或切换而中断；需要连续处理大量文章时，优先使用单 worker 的 Docker Compose。

## 7. 常见问题

### 扫码后没有进入公众号列表

确认扫码使用的是微信 App，并在手机上完成登录确认。若出现双重验证码，必须在网页输入手机显示的 4 位数字。二维码过期后请重新生成，不要继续提交旧任务。

### 获取不到历史文章

先确认公众号已在微信读书中关注，再点击“刷新”更新公众号列表。调整日期范围后点击“按日期读取”；结果仍然受微信读书未公开接口和单次安全上限限制。

### 下载任务长时间没有变化

保持当前页面和会话有效，点击“重新查看进度”。如果连接已经过期，重新连接微信读书后重新读取列表，再重试失败项。Vercel 部署遇到函数超时或实例切换时，改用 Docker Compose 运行。

### 图片没有全部下载

微信媒体地址可能过期、受限或超出单张大小限制。重新执行失败项；无法下载的图片会继续保留原图链接，不影响 Markdown 正文导出。
